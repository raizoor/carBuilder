# cardBuilder
Component used to study Java + Spring Boot news, based on fictional necessity of an car industry to decide with which partners work to.

## Business ##
After creating a car prototype, a car manufacturing company needs to create a final proposal for prior evaluation before production begins, taking into account all the components that it does not produce itself (e.g. wheels). To do this, software is needed that knows all the available suppliers for each part and, through certain criteria, makes an automated decision regarding the best proposal for parts to be used within the model in question.
